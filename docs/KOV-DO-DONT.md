# KOV — Do / Don't

Référence rapide non négociable. À relire avant toute session de travail (humaine ou IA) sur le site KOV.

## Les 8 règles non négociables

1. Le site est une expérience continue, pas une succession de sections.
2. Le scroll contrôle les transformations de l'univers.
3. 3D en arrière-plan, contenu réel en HTML au premier plan.
4. Noir dominant, blanc pour la lecture, rouge uniquement comme signal.
5. Brutalisme architectural + Liquid Glass fonctionnel.
6. Le personnage KOV est un guide, jamais une mascotte.
7. Chaque scène doit physiquement devenir la suivante.
8. Performance, lisibilité et conversion restent prioritaires sur l'effet wow.

## Interdit

- landing page SaaS classique
- grid de cartes partout
- grosses pills
- gradient violet/bleu
- néons
- cyberpunk
- crypto aesthetics
- grosse sphère 3D
- particules gratuites
- hologrammes bleus
- emojis
- stock images
- illustrations corporate
- glassmorphism partout
- animation bounce
- scrolling horizontal gadget
- 3D décorative sans fonction

## Univers 3D — matières autorisées

Béton noir, béton brut, métal noir, verre fumé, verre transparent, OLED noir, aluminium sombre, surfaces mates. Quelques réflexions autorisées.

**L'univers ne doit jamais devenir** : cyberpunk / gaming / sci-fi flashy.

## Lumière

Grandes lumières blanches indirectes, rim lighting, zones très sombres, lumière architecturale, reflets extrêmement contrôlés.

Le rouge en lumière uniquement sous forme de ligne, voyant, trace, marqueur, source ponctuelle — jamais une pièce entière éclairée en rouge (sauf transition exceptionnelle).

## Architecture (univers 3D)

Espaces monumentaux, géométriques, très sombres, presque muséaux, relativement vides. Références conceptuelles : architecture brutaliste + galerie contemporaine + installation digitale. Beaucoup d'espace négatif — nécessaire pour que les textes HTML puissent apparaître dans ces zones.
